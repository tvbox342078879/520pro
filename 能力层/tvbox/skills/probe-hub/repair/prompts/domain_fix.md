# domain_fix（换域修复）· 分型=域名层

你在修一个失效的 TVBox Python 源。死因分型：**域名层**（原域名不可达/证书死）。

规则（硬约束）：
1. 只允许换域名/拼接地址：`host` / `self.host` / 所有 URL 拼接处全覆盖
2. **严禁臆造新接口路径**；接口前缀改版只允许基于真请求证据（`<untrusted_web>` 包裹内容）
3. 检查接口前缀是否改版（/api、/index.php/ajax 变体），有真证据才改
4. 新域名来自证据包里给出的候选域，不许编造
5. 输出 JSON patch（edits.old 必须原文逐字片段）

换域后立即复验（真跑体检），复验不过重新分型。
