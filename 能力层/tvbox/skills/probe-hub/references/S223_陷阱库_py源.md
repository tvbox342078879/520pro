## A. 症状：封面全灭 / 图片不显示

| 判据 | 修法 |
|---|---|
| `getProxyUrl()` 硬编码 `do=img` | 壳把它当**内置图片转发器**，根本不转发给本源 `localProxy`。必须 `do=py`，URL 含「`do=py` + `url=` + `type=img`」三要素 |
| `_img_proxy` 拼接无脑 `+"&url="` | 入口已带 `?` 时拼错。用 `sep = "&" if "?" in base else "?"` |
| 魔数统一按 4 字节判 | **JPEG 前 4 字节是 `ffd8ffe0`，永远匹配不到 4 字节元组 → 合法 JPEG 被静默丢弃**。3 字节判 JPEG/GIF，4 字节判 PNG/RIFF |
| 大图不显示、小图正常 | 纯 Python AES 解大图 12~18s，超出壳端图片加载窗口。**>100KB 必须 pycryptodome** |
| AES 解密失败直接 `return data` | 返回密文→壳端显示乱码占位。必须：解密 → 验魔数 → 失败返回 None |
| 封面域名少个 `s`（`asserts` vs `assert`） | 抓 HTML 里真实出现的域名，禁凭记忆；交付前 grep 硬编码域名逐字符比对 |

## B. 症状：黑屏 / 拿不到浏览器地址但播不了

| 判据 | 修法 |
|---|---|
| 拉回 `text/html` 或 `push://` 网盘 | **头号根因**，一律剔除 |
| host 是 `localhost`/`127.x`/`10.x`/`192.168.x` | 采集站自己后台地址，客户端请求=请求手机自己。换站点 host + 百分号编码；仍不行如实写「本站未对外暴露」 |
| 拉回 `image/png` 但长度反常 | 站点伪装 m3u8 成 .png 有解码法（剥 PNG→gzip→真流）。别当坏源剔掉 |
| `#EXT-X-MAP` 未改写 | fMP4 初始化段不走代理 → 黑屏。连 `#EXT-X-MEDIA`/`I-FRAME-STREAM-INF`/`PART` 的 `URI=` 一起改 |
| `#EXT-X-KEY` 用 `str.replace` 改 | 短名 URI（`key`/`k`）会把整行都换掉。用切片 `line[:m.start(1)]+新值+line[m.end(1):]` |
| IV 解析 `replace('0x','')` | 遇大写 `0X` 不生效 → 静默退化成全零 IV。用 `re.sub(r'^0[xX]','',iv)` |
| `Accept-Encoding` 换响应 md5 就变 | 壳内 IJK/FFmpeg 解不了 br/gzip。`playerContent` 的 header 必须带 `Accept-Encoding: identity` |

## C. 症状：分类点开空 / 搜索只有一页

| 判据 | 修法 |
|---|---|
| `/page-N.html` 返 200 但 0 卡片 | 页面有 `refresh_gallery(...)` 之类刷新脚本 = 服务端只给壳。改用 `?page=N` |
| 真分页判据 | 两页 `vod_id` 集合 **overlap=0**；单页接口两页同数据 |
| 搜索翻页路径 ≠ 列表路径 | 必须分别实测（列表 `?page=N`、搜索 `/search/KW/page-N.html`） |
| 壳下滑不回传 `pg`（None/""） | `_page_of` 多源兜底：`pg>1` > `quick>1` > 同 key 状态机自增 > 1；`int()` 一律 try/except |
| 满页才 `pagecount=p+1` | 未满页 `pagecount=p`，否则壳端无限下滑空白页 |
| 服务端硬上限（`pg>N` 恒空且 ok:1） | 三查：`page>N` 短路、`min(page+1,N)` 封顶、区分「越过上限」与「限流假空」。**N 必须实测，禁沿用** |

## D. 症状：筛选点了不换内容

| 判据 | 修法 |
|---|---|
| 年份写死 `2022-2025` | 用 `_years()` 动态（当前年起近 4 年） |
| `total_results` 当判据 | TMDB 克隆类恒为硬上限 20001，**总量字段不能当行为判据**。取结果项级字段（`genre_ids` 逐条是否含目标 id） |
| 带/不带筛选首条相同 | 服务端静默忽略该参数。逐个候选值 GET 对比 `vod_id` 集合 |
| 羊壳无筛选栏 | 羊壳 `Class.writeToParcel` **不写 filters** → 顶层丢失。`c['filters']=filters.get(tid)` 内嵌进每个 class 项 |
| 组页筛选不生效 | 组页 filters **首项必须 `cat`**（影视壳只认首项），其余参数全链透传并落进缓存键 |

## E. 症状：首屏慢 / 冷启动白等

| 判据 | 修法 |
|---|---|
| 冷启动首屏 19.5s | `POOL[0]` 是不达域，每次白等一次完整超时。**池序热域前置** + 命中域 `remove()+insert(0)` + 超时 ≤6s |
| 后台预热反而更慢 | 全量并发+详情二次校验抢 DNS/连接资源。改轻量探测（少候选+短超时+命中即返）+ 延迟启动 |
| 分类点开 127s | 列表阶段对每张卡逐条抓详情（`_enrich` 式富化）。删富化 + 真分页 + 详情短 TTL 缓存 60s |
| `for` 循环里有网络调用 | 生成 12 张卡调 12 次 `_cover()`，首访 25.5s。卡片即时返回代理 URL + 后台预热 + 本地缓存 |

## F. 症状：反爬 / 请求失败

| 判据 | 修法 |
|---|---|
| 首页 HTML 只有 ~2KB | 落地页壳（点"立即进入"才跳）或需先种 cookie。`requests.Session` 先 GET 首页 |
| 同路由换词就 200（内容型 RST） | **分型实验必须先做**：等长对照词 ≥2 组含 1 组成功 → 内容型。同域重试**一次**即降级，禁跨域轮询 |
| 降级路由等价性 | 改走 `/tag/{kw}/`，**判据是首条 ID 一致**；翻页格式常不同（`/page/N/` vs 末尾 `/N/`），必须两种都兼容 |
| 发布页域名被别家占用 | 同一模板多家共用。**解密出的域名必须验证目标站结构特征**，HTTP 200+大 HTML 不是采用证据 |
| 「不能自动获取域名」 | 病根常是发布入口写死单域名且已死。改 live 多域名列表，每个入口独立 try 自足解码 |
| `CDN-Lah` 496 + `Lah-Server` 头 | 需浏览器执行 JS 拿指纹 cookie，纯 requests 无法绕。只能等壳端 WebView 过盾带 cookie 用 |
| 混淆 JS（`eval(function(...){...})`） | 连续 2 次 stub 报「未知全局/不是函数」立即停。先 grep 静态配置（embed/player/services） |
| 伪装 UA/加头/带 cookie 全无效 | 许可在页面 JS 运行时上下文，纯 requests 复刻不了。**到边界即停**，改壳侧页面上下文方案 |

## G. 症状：壳加载后没数据 / 分类空白

| 判据 | 修法 |
|---|---|
| 顶层 `from Crypto.Cipher import AES` | 羊壳无 Crypto 库 → 导入失败 → 整个文件挂。try/except 降级纯 Python |
| `self.classes` 设在 `_resolve_domain()` 之后 | 域名解析异常中断 init → 分类页空白。**classes 最先设置**，域名解析整体 try/except |
| `init(extend)` 只认一种填法 | 必须兼容 4 种：纯 URL / 省略协议 `a.b:18889` / JSON / dict |
| `verify=False` + `check_hostname=True` 冲突 | 必须提前双关 `CERT_NONE`/`False`，否则整个 session 挂 |
| shell 端看不到 print | 调试写文件 `/sdcard/<name>_debug.txt` |
| 所有 `get()` 都要带 `proxies=` | 只赋值 `session.proxies=p` 在异常重试时可能绕过 |

## H. 症状：格式对但语义错（第二把尺子）

| 判据 | 修法 |
|---|---|
| 三层切分只验格式 | `$$$` 面板数==线路数、`#` 每段恰 `名称$URL` 两段。**还要跑语义断言**（见下） |
| 线路不可区分 | `(线路名, 归一化首集URL)` 二元组互异。同名+同源=FAIL，同源不同名=WARN |
| 集名重复 | 同一 from 内 `#` 分隔的集名不重复 |
| `_time` 标签语义漂移 | 同站可能分别是发布时间/时长/更新相对时间。**同页多处采样 + 详情页交叉验证**，单样本禁定论 |
| 特殊分类走页面直链 | 与普通分类走**同一条已验证 API**，页面直链只作兜底 |
| 某几个分类空、其它正常 | 先扫 1..N 找哪几个 id 真有卡（id 被重排/下架），死 id 从 home/category **两处同步删** |

## I. 铁律（违反即作废，来自 rules.md）

1. **禁自加推荐分类**（用户明令钉死）：`class` 只许照搬站方真实导航，即使站方有「推荐」也默认移除。
2. **分类名/集名/线路名原样**：禁「分类1」、禁拿 id 当名字、禁把集名写成 URL。
3. **分页必须实测区分真分页/单页**：禁 9999 谎报页数。
4. **交付版零注释/零docstring/零空壳/零`__main__`**（解密段豁免 ≤3 行头部注释）。
5. **冷启动池首必须是实测验活热域**。
6. **用户验证版 = 金标准**：改播放链路前先 `cp` 备份，用户说播不了立刻回退。
