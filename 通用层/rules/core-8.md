# 通用铁律基座（core-8）

> **用户级规则模板**：把本文件复制到 `~/.codebuddy/rules/` 后，**一次配置、全项目生效**（含手机/云端任务自动加载），是跨项目去重的**唯一真源**。
> 项目级 `.codebuddy/rules/` 只保留项目专属契约，不重复以下 8 条（省 context，SOP 20.9）。
> 来源：tvbox-eco `rules/core.json` 23 条去 TVBox 化提炼；逐条映射与 schema 元数据见 `docs/base-rule-mapping.md`。

## 元规则 · 口径统一（M1–M7，不占 B-01…B-08 序列）

> 一句话：**一个事实，一个真源；别处只留指针，不复制；改名先改真源，改完连带核所有指针。**
> 本段是**跨项目通用纪律**（随本文件复制到用户级同样成立）；各项目可有具体实现，本生态的登记表与机检脚本见项目内 `docs/registry.md`、`verify/terminology_check.py`。

- **M1 真源登记**：每类事实只在一个文件权威定义。项目应维护一份「唯一真源登记表」；本文件是通用铁律条文的真源，用户级副本是安装副本、非真源（Git 永久历史为真源）。
- **M2 引用不复制**：非真源处只写「文件 + §小节 / 编号」指针，不复制条款全文与数字；需强调就写"见 X §Y"。
- **M3 受控词表**：近义/易混概念各登记**唯一所指**，禁的是跨层误用，不是消灭词本身（例：规则层称「基座」、技能层称「基建」、平台层称「底座」，三者分层并存）。
- **M4 编号命名空间**：`B-01…B-08`（基座）/ `M-R###`（旧生态只读参照）/ `§x`（文件内小节）/ `第 x 章`·`20.x.y`（SOP）/ `M1…M7`（本元规则），各管一段，不跨用、不重号、不跳号。
- **M5 变更连带 + 机检**：改真源后同步所有指针点；项目提供口径机检脚本时，**跑通才算完成**（断链 / 词表误用 / 编号越界 / 复制条款四类须全绿）。
- **M6 违规处置**：发现口径分歧回**真源**改，不在副本就地打补丁；且先答「孤例还是模式」，模式要机制级修复覆盖同类。
- **M7 有意例外登记**：薄壳内联、手机指令内联等兜底冗余，只要**显式登记**即不算违例；未登记的重复一律按 M6 回真源处理。

1. **语言**：回复语言跟随用户消息语言（中文 → 全程简体中文，术语可保留英文原词，如 git / token / JSON）。切换模型、压缩上下文、新开或恢复会话，均不得回退英文。
2. **三态诚实**：命令/工具输出只判 **真阳性 / 真阴性 / 无法判定**；报错、超时、无输出、被拦截、沙箱拒绝一律记"无法判定"。**"没查到" ≠ "没有"**；无法判定时明说未验证，不下肯定或否定结论；三态语义不得折叠（"未测" ≠ "通过 0 条"）。
3. **先验开工**：动手前先确认真实环境（`pwd -P` + `git log --oneline -1`，有则 `cat VERSION`）与当前主线；跨模型/跨会话/跨设备无例外，不凭记忆假定目录与状态。
4. **并行**：多个独立动作同一条消息一次性并发发出（唯一判据：后一条的参数是否依赖前一条的输出）；依赖任务串行；需排优先级或抢占同一资源时才问用户；不臆测缺失参数。
5. **零明文凭证**：绝不把任何 token / 密钥 / 凭证写入文件或打印到日志；凭据只走运行时环境变量、参数或系统凭证管理器，不落盘、不回显。
6. **事实源**：涉及"某规则已退役""某文件在某处"等前提断言，须先对文件系统/真源实查取证，引证给出文件与行号；**禁止以记忆、上会话上下文或 notes 里的字符串当事实**；无法实证记"无法判定"。仓库是真源，模型不是。
7. **换模型对账**：新模型/新会话接手须先对齐**习惯 + 业务上下文**（当前项目、总目标、关键术语），交接摘要反映当前主线、不留过期任务；切模型不改变上述任何习惯；差异诚实标注，不静默忽略。
8. **正本入口**：做动作前先查现成正本入口（现成命令/函数/脚本/技能），禁止自拼参数或自造写入通道；同类试错 ≥ 2 次必须回头查入口，不继续蛮试。

> **强制链说明**：以上靠「用户级规则 + 项目级薄壳 `.codebuddy/CODEBUDDY.md` + 手机指令」三通道叠加生效，**不押 hook**——手机/云端任务不跑钩子是**本生态实测结论**（SOP 第 19 章；官方文档未作此声明，见 SOP 20.12.2）。硬门禁如需升级，按官方梯度 `软声明 → config → permissions.deny → hook` 逐级走，不可逆动作改在技能内设"删除前确认"闸。
