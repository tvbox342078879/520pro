## 何时使用
- 触发词（唯一真源）：换机 / 新设备 / 重装 / 迁移 / 初始化环境 / 一键克隆 / 重建工作副本 / 装机脚本
- 新设备接入、重装、迁移、协作克隆，或用户要求初始化环境时。

## 工作流
1. 确认源地址；用户没给就**开口问，不猜测、不写死**。
2. 执行换机司脚本。**脚本在仓库根 `bootstrap.sh`，不在本技能目录内**（技能目录只发说明书；手机/无仓库场景按 `手机指令.md` 的 `curl` 一行拉取）；参数是**位置参数**，无 `--repo/--sparse`：
```bash
bash bootstrap.sh "<本生态 git 地址>" full ~/520pro --install
#   位置1=源  位置2=shape(full|lite)  位置3=目标目录
#   --dry-run 只打印不落盘；--install 换机后自动装技能
```
3. **不提供 `--verify`**：官方 Skills/Memory/Settings 文档均无此能力，脚本也没有该开关——三通道是否到位改用 L2 三态实测确认（`.codebuddy/CODEBUDDY.md` 薄壳、`.codebuddy/rules/`、手机端「会话首条粘贴」材料即云端 doc「手机指令粘贴区」——App 内无指令入口为 2026-11-13 两版实测定论）。不得宣称 `--verify` 通过。

> 2026-11-12 修正（工程D 施工时实查）：原文写"可选件、本脚手架未搬入"且给了 `${CODEBUDDY_SKILL_DIR}/scripts/bootstrap.sh --repo --sparse`——脚本实际早在仓库根，且无这两个参数。照原文跑必然失败，属文档断链，已改正。
4. 报告结果按三态：**真阳性 / 真阴性 / 无法判定**；不以"没查到"充当"没有"。

## 职责与边界
- 只重建**工作副本**，不整库全拉（产物/资料库不进工作副本），不重搭规则与记忆。
- 幂等：重跑安全。零明文 token：凭据一律走环境变量或参数；脚本以 `grep -R "ghp_"` 自检，命中即中止告警。
- 不删除远端任何内容，不替用户决定业务内容；破坏性操作需用户确认后执行。

## 诚实边界（v1.0.3 起，换机前必读；借鉴 908 换机说明的边界表模式）

| 边界 | 说明 |
|---|---|
| 只搬代码与规则真源 | 产物/交付物**不进工作副本**——它们落云端资料库（B-09），换机登录即得，不在本技能职责内 |
| 账号侧配置不搬 | App 偏好、桌面设置入口等跟随账号云端同步，无需也不应进仓库 |
| 会话历史不搬 | 手机/桌面会话记录属本地；要留的证据应已沉淀进仓库或资料库（B-14 账目有落点） |
| 云端资产零动作 | 资料库/云端 doc 天生跨设备，本技能不碰、也不需要碰 |
| 凭据只走运行时 | **不给 URL 内嵌 token**（那会明文持久化进 clone 的 `.git/config`，B-05 红线）；走环境变量或凭证管理器 |
| 平台钩子不作为依据 | 手机/云端任务不跑钩子（实测定论），换机校验以三通道**文件在位**为准，不押钩子 |
| 手机端用法 | 手机无指令入口（2.8.0/2.9.1 实测）：新会话从云端 doc「手机指令粘贴区」复制首条粘贴，与本技能无冲突 |
