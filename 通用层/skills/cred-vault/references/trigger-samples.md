# cred-vault 触发样本集

> **判据真源**：`SKILL.md`（能力/边界）。本文件只放样本。
> **登记**：`verify/skill_contracts.json` → `trigger_samples`；C6 机检 T≥8/N≥6/B≥3；C10 词桥（每条 T 的中文双字词须在 description 出现）。

## T 组 · 应触发（T≥8）

### T01
- Prompt：`把这个 cookie 加密保存，别明文放着`
- 为什么该触发：cookie 加密落盘是本技能核心
- 预期第一动作：读 SKILL 正门段 → `cred_vault.py --help` → `key-init` → `seal --domain` 加密 0600 落盘
- 不许：把 cookie 明文写进脚本或日志

### T02
- Prompt：`token 帮我安全落盘，怕明文泄露`
- 为什么该触发：token 安全落盘 + 明文风险是本技能对象
- 预期第一动作：确认密钥文件在仓库外 → `seal` 加密 → `key-status` 验在位
- 不许：用 base64 当加密

### T03
- Prompt：`密钥泄露了，怎么让所有旧密文一次性失效`
- 为什么该触发：密钥轮换一次性全局失效标记是本技能机制3
- 预期第一动作：解释 mark_key_lost 一次性标记 → 密钥重建 → 旧密文全失效提示重登
- 不许：逐字段试解密碰运气

### T04
- Prompt：`不同网站的凭证能用同一套加密吗，会不会串`
- 为什么该触发：域分离 AAD 正是防跨站点密文重放
- 预期第一动作：解释 domain 作 AAD → github_token 域解不开 baidu_cookie 密文 → 实证跨域拒绝
- 不许：说共用一个密钥就没事

### T05
- Prompt：`密钥文件损坏了，凭证还能恢复吗`
- 为什么该触发：密钥自愈（删条目重建重试一次）是本技能机制3
- 预期第一动作：走 with_retry 验证重建换钥 → 说明旧密文随之失效需重登
- 不许：静默跳过损坏继续用旧钥匙

### T06
- Prompt：`给我讲讲 AES-GCM 加密信封是怎么组织的`
- 为什么该触发：加密信封 wbcred:v1 是本技能机制1
- 预期第一动作：解释信封 wbcred:v1:<b64IV>:<b64CT> + tag128 + PBKDF2 派生
- 不许：手写一版 AES 替代正门

### T07
- Prompt：`凭据泄露排查，看看明文口令有没有落盘`
- 为什么该触发：口令零明文（运行时注入）是本技能边界
- 预期第一动作：查 secret_scan + 凭证名登记真源 → 说明口令只走 --passphrase-env 运行时注入
- 不许：把口令写进配置文件

### T08
- Prompt：`PBKDF2 派生要多少轮才算安全`
- 为什么该触发：PBKDF2 21万轮是本技能参数（云取实证）
- 预期第一动作：答 210000 轮（云取 AuthCrypto 实证）+ 引判据常量
- 不许：随便给个小轮数

## N 组 · 不应触发（N≥6）

### N01
- Prompt：`把这个百度网盘链接转存到我的网盘`
- 应归谁：learn-hub 的 pan.py save（本技能只做凭证加密，不做转存）
- 不许：本技能接转存

### N02
- Prompt：`帮我把这篇公众号文章排版发草稿箱`
- 应归谁：wechat 发布类技能
- 不许：本技能碰公众号发布凭证

### N03
- Prompt：`我忘记了百度网盘账号密码，帮我找回`
- 应归谁：账号找回流程（非本技能，本技能不保管口令）
- 不许：本技能做口令记忆/找回

### N04
- Prompt：`把这个加密文件用 openssl 手动解密`
- 应归谁：openssl 命令行（用户明确指定工具时）
- 不许：本技能阻止用户用自己的工具

### N05
- Prompt：`配置一个云端的密钥托管 KMS 服务`
- 应归谁：云厂商 KMS（本技能只做本地 0600 落盘，不做托管服务）
- 不许：本技能冒充 KMS

### N06
- Prompt：`这个网站登录不上去，帮我重置密码`
- 应归谁：网站账号流程
- 不许：本技能接账号重置

## B 组 · 边界样本（B≥3）

### B01
- `用户只是问「token 是什么」→ 概念问答，不触发本技能加密动作`

### B02
- `凭证已在第三方保险箱（1Password 等）→ 本技能不接管，不触发`

### B03
- `密钥损坏但用户不希望重建（要保留旧密文）→ 本技能重建会令旧密文失效，须先确认，不擅自重建`
