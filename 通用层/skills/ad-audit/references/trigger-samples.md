# ad-audit 触发样本集

> **判据真源**：`SKILL.md`（能力/边界）。本文件只放样本。
> **登记**：`verify/skill_contracts.json` → `trigger_samples`；C6 机检 T≥8/N≥6/B≥3。

## T 组 · 应触发（T≥8）

### T01
- Prompt：`查这个百度网盘文档正文有没有微信引流`
- 为什么该触发：问的就是 docx 正文微信引流
- 预期第一动作：读 SKILL 正门段 → `ad_audit.py --help` → 解析分享链接/提取码 → 走 ad-audit 一键命令
- 不许：自己写 requests+OCR 脚本

### T02
- Prompt：`这份周刊 docx 帮我扫一下正文广告`
- 为什么该触发：docview→PDF→OCR 正文广告排查是本技能核心
- 预期第一动作：确认 docx 来源（百度分享）→ 优先复用 `--meta` 预列元数据 → 扫首尾页
- 不许：只看文件名判断有没有广告

### T03
- Prompt：`网盘分享的周刊里是不是加了二维码和 xmly`
- 为什么该触发：二维码/xmly 是本技能命中词
- 预期第一动作：走 ad-audit → 报 `hits` 词频 + 期号，三态标注
- 不许：把 `无预览` 判成「干净」

### T04
- Prompt：`商业周刊这两期正文带不带加我微信`
- 为什么该触发：商业周刊正文广告复核是既有落地场景
- 预期第一动作：`--match` 按文件名筛期号 → 全链 OCR → 对照历史清单出差异
- 不许：只扫一个样本就以点盖面

### T05
- Prompt：`把收藏的百度文档批量做正文广告排查`
- 为什么该触发：批量全量扫描属本技能
- 预期第一动作：确认 cookie/预列元数据 → 后台跑全量 + 结果 JSON 落盘
- 不许：前台死等挂住回合

### T06
- Prompt：`这个 pdf 是从网盘下的，看看有没有作者引流`
- 为什么该触发：作者 embedded 引流是排查对象
- 预期第一动作：判来源（百度分享链）→ 走 ad-audit；本地单 PDF 则直用 pan.py ad-audit
- 不许：凭文件名断言无广告

### T07
- Prompt：`监测的周刊链接里，正文广告全量扫一遍`
- 为什么该触发：全量扫描 + 清单是本技能交付
- 预期第一动作：复用已列元数据 → 全量 → 带广告/干净/无法判定三分 + JSON
- 不许：把无法判定并进干净数

### T08
- Prompt：`docx 里 embedded 的微信二维码怎么查出来`
- 为什么该触发：正文内嵌（不在文件名）的引流是本技能专门能力
- 预期第一动作：解释 docview→dlink→PDF→OCR 原理 → 走 ad-audit 实证
- 不许：说"文件名过滤就行"

## N 组 · 不应触发（N≥6）

### N01
- Prompt：`把这个百度网盘链接转存到我的网盘`
- 应归谁：learn-hub 的 pan.py save（本技能只排查广告，不做转存）
- 不许：本技能接转存

### N02
- Prompt：`把这篇公众号文章整理成学习资料`
- 应归谁：learn-hub（学习资料整编）
- 不许：本技能做资料整理

### N03
- Prompt：`本地这个 PDF 文件编码乱码怎么修`
- 应归谁：pdf 技能
- 不许：本技能修编码

### N04
- Prompt：`这个网页上的广告怎么屏蔽`
- 应归谁：浏览器/广告拦截工具
- 不许：本技能做网页广告拦截

### N05
- Prompt：`帮我把周刊 docx 里的广告删掉`
- 应归谁：文档编辑类技能（workbuddy-office-routing → workbuddy-local-office-edit）
- 不许：本技能只排查不改写文档

### N06
- Prompt：`这个视频里有没有植入广告`
- 应归谁：视频分析类能力（非本技能，本技能只管 docx 正文文本）
