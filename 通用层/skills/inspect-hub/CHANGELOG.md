## v1.4.1 — 景门改集合比对（工程G-2，2026-11-12）
- **`chk_docsync` 重写**：旧判据拿登记册写死的 `declared` 常量比代码计数，代码加个子命令、没人记得改登记册，这面就永久红（实测 space-hub 登记 14、代码 19，连续几轮红着）。**假红的价值等于零还倒扣信任**——人一旦习惯"这面老是红"，真吹牛就淹了
- 新判据两边都现读：文档命令集 vs 代码子命令集，报"多哪个/少哪个"而不是"数字不等"
- 分级：文档有代码无 = 红（吹牛，用户照敲会报错）；代码有文档无 = 黄（仅 `check_missing=true` 时——命令极多的技能只列主命令是设计选择）
- 只在 ``` 代码块内抽命令：正文里 "probe tvbox 相关" 曾被误抓成吹牛；且用水平空白不跨行（`\s+` 会把行尾 probe 与下行 tvbox 连成伪命令）
- 抽样为空 → unknown（不许把"两边都没抽到"说成一致）
- 回归：`verify/tests/test_docsync.py` 8 项（真仓绿 / 吹牛红 / 漏写黄 / 抽样空 unknown）
