# artifact-store · 故障排查（按症状查）

> **怎么用**：本地轻量化的坑几乎都是"**清早了 / 删多了**"。
> 机检：`verify/tests/test_troubleshoot.py` 要求 ≥5 条真实条目。

## 1. 清完本地，才发现云端没有那份东西

- **先查**：云端有没有、是不是同一个版本（按名称+日期比对，不按"我记得传过"）。
- **怎么办**：先补传再清本地；已清的从资料库/回收站找，找不到就如实报"已丢"。
- **别做**：不要把"云端有备份"当默认前提——必须先验证（B02 已固化进样本集）。

## 2. 更早的产物还能找到吗？本地只剩最近两轮

- **先查**：这是设计（本地只留 2 轮），更早的应在资料库。
- **怎么办**：去「📦 产物归档」按日期/来源查；找不到就是归档那步失败了，看当时日志。
- **别做**：不要关掉轮换让本地全留——手机变卡的主因之一就是本地产物堆积。

## 3. 归档失败，文件还在本地

- **先查**：库务司是否安装、是否授权、网络是否通；失败通常是"只提示不阻断"。
- **怎么办**：修好后 `products --retry` 补投；确认索引里出现记录再清本地。
- **别做**：不要手工把文件挪进资料库——那样没有索引记录，等于"失踪"。

## 4. 手机用久了变卡

- **先查**：是不是上下文/记忆/规则全量加载 + 本地产物堆积（§8 本地轻量纪律）。
- **怎么办**：`/clear` 重置会话、按需加载记忆、产物走 LRU 归档；规则用 `paths` 条件触发。
- **别做**：不要靠"删聊天记录"解决——那会丢决策上下文，卡顿根源常在别处。

## 5. 误删了本地文件，想找回

- **先查**：资料库里有没有同名同日的归档；`/tmp` 或会话产物区有没有副本。
- **怎么办**：从资料库下回；确实没有就如实报，不要"重建一个差不多的"冒充原件。
- **别做**：不要在没有备份的情况下对大目录做批量删除。
