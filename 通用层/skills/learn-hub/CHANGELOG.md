# learn-hub CHANGELOG

## 1.4.0 — 学习成品自动进资料库（2026-11-12）

- **★ 出口接线**：`store put` 入库成功后自动把成品交到「📚 学习资料/成品」——
  **主文档**（index.md > README.md > 唯一 md）单独建成文档节点（云端可直接读正文、按标题检索），
  **整目录打 zip** 兜底（附件/图片/数据一份不丢）。
- **三态不折叠**：多个 md 又无 index/README → 不猜，返回空主文档并如实写进索引
  「未识别到主文档（无 index.md / README.md / 唯一 md）」，改走整包入库。
  主文档归档失败也降级整包，说明里写清失败原因。
- **索引只记一条**：zip 用 `write_index=False` 只上传不建记录（一份成品两条记录会让人以为入库两次）。
  说明列写「N 文件｜主文档 xxx.md｜整包 xxx.zip 同夹」，到资料库一眼知道是哪份。
- **失败不阻断**：未装库务司 / 无授权 / 断网 → 只提示，本地 `library/` 照常入库
  （本地才是主存储，云端是"让人找得到"的补充）。

## 1.3.0 — 清理门面改道库务司本地欠账（2026-11-12）

- `_to_janitor` → `_to_spacehub`：原走 tvbox-core 的 file_to_janitor（云端通道），投本地残留路径被 S156 node_id 护栏拒收——名义联动，投递从未成功。改调 space_hub.auto_file_local（本地欠账登记），记账→出单→销账闭环。
- 依赖解耦：学习工坊（通用层）不再依赖能力层 tvbox-core。
