# 植物生长调节剂 · 农户操作卡

> 三源核实：中国农科院、中国农药信息网(ICAMA)、浙江省使用规范。正文每条带 [出处]，无出处单列。

## 一、它是什么（一句话）
人工合成、作用和植物激素类似的物质，用来调作物生长、稳产增产——按登记标签用是安全的 [出处：中国科学报2015-06-10·中国农科院转载 caas.cn 李香菊/叶志华访谈]

## 二、四大类 + 常见品种
- 促进剂：赤霉素、萘乙酸、芸苔素内酯、乙烯利 [出处：中国农科院·功效分类]
- 延缓剂：矮壮素、多效唑、氟节胺 [出处：中国农科院·功效分类]
- 抑制剂：氯苯胺灵、脱落酸、抑芽丹 [出处：中国农科院·功效分类]
- 保鲜剂：⚠️ 无出处（原文只提"还有一类保鲜剂"未列具体品种，不编造）

## 三、按用途选药（照做）
- 促种子发芽：赤霉酸 / 吲哚丁酸 / 复硝酚钾 [出处：浙江省生物多样性友好规范 §6.1]
- 促生根：吲哚乙酸 / 吲哚丁酸 / 萘乙酸 / 复硝酚钾 [出处：浙江规范 §6.2]

## 四、登记作物对照（用前必查）
- 芸苔素内酯：登记作物最多——黄瓜、番茄、辣椒、苹果、梨、柑橘、葡萄、草莓、香蕉、水稻、小麦、玉米、花生、油菜、大豆、叶菜、荔枝、龙眼、棉花、甘蔗、烟草 [出处：ICAMA 用药对照表第8项 icama.org.cn/kgls/detail/25353]
- 乙烯利：番茄、玉米、香蕉、荔枝、棉花 [出处：ICAMA 对照表第7项]
- 赤霉酸A3：梨树、水稻、菠菜、芹菜、大白菜、烟草 [出处：ICAMA 对照表第4项]
- 萘乙酸：水稻秧田、小麦、苹果树、棉花、番茄、葡萄、荔枝 [出处：ICAMA 对照表第1项]
- 一种调节剂不是对所有作物都有效，可能无效甚至有副作用——必须查登记标签 [出处：中国农科院·李香菊访谈]

## 五、五条安全底线
1. 买取得农药登记证的合法产品，看标签有效成分/用法/注意事项 [出处：中国农科院；浙江规范 §5.2.1]
2. 严格按标签剂量、时期、方法用，超量反伤产量品质 [出处：中国农科院；浙江规范 §5.3]
3. 选低毒低残留，残留不超标准，遵循 GB/T 8321.4 [出处：浙江规范 §5.3.1-5.3.2]
4. 避免对非目标生物影响，按需施用、用后监测 [出处：浙江规范 §5.1]
5. 我国登记品种41个（2015年口径）——时点较老，用前须查 ICAMA 最新登记 [出处：中国农科院；⚠️ 时点待复核]
