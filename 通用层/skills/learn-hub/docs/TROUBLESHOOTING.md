# learn-hub · 故障排查（按症状查）

> **怎么用**：学习工坊的坑集中在**"料拿不到"与"成品进了本地没进云端"**。
> 机检：`verify/tests/test_troubleshoot.py` 要求 ≥5 条真实条目。

## 1. 网盘分享链接解析失败

- **先查**：`python3 scripts/pan.py info --url "<分享链接>"` 的原始返回；链接是否过期/需要提取码/被限流。
- **怎么办**：补提取码、换时间重试；确认平台（夸克/UC/迅雷/百度）与脚本支持的一致。
- **别做**：不要把"解析失败"写成"文件不存在"——那是两件事（一个是权限/风控，一个是真没有）。

## 2. 入库成功，但资料库「📚 学习资料/成品」里没有

- **先查**：库务司（space-hub）装没装、有没有授权；入库日志里有没有"未装/无授权/断网，本地已存"的提示。
- **怎么办**：装上 space-hub 后 `products --retry` 补投；本地 `library/` 里的成品还在，不会丢。
- **别做**：不要因为"本地有"就以为"云端有"——出口失败是**只提示不阻断**，很容易漏看。

## 3. 多个 md 但没有 index/README，不知道哪个是主文档

- **先查**：看有没有命名规律（如 `*_主文档.md`）或目录里唯一的大文件。
- **怎么办**：如实把"主文档=空/未判定"写进索引，让人来指定；或用 `store put` 时显式指定主文档。
- **别做**：不要猜一个"看起来最像"的当主文档——猜错会让索引长期指向错文件。

## 4. 一份成品在索引里出现两条记录

- **先查**：是不是 zip 与主文档各建了一条；`write_index=False` 的参数有没有传。
- **怎么办**：zip 只上传不建记录（`write_index=False`），主文档一条记录即可。
- **别做**：不要靠事后删记录解决——下次入库还会重复。

## 5. 提示找不到 tvbox-core / 依赖缺失

- **先查**：学习工坊是通用层技能，**不依赖**能力层 tvbox-core（已解耦）。
- **怎么办**：按报错找真实缺失模块；网盘取料用 `pan.py`，不要去找 probe-hub 的旧入口（已迁出）。
- **别做**：不要为了"跑通"去装 tvbox-core——那是把通用层绑回业务层。
