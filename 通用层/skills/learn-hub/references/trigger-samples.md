# learn-hub 触发样本集（学习工坊）

> **用途**：触发回归。判三件事——该触发时**有没有触发**、不该触发时**有没有乱触发**、触发后**第一动作对不对**。
> **为什么要写清反例**：本技能边界外挂着 5 个兄弟技能（出卷/框架/PPT/错题/格式转换），误接一条就白干一轮。
> **判据真源**：`SKILL.md`（能力 ①-⑦、★边界、正门 `scripts/learn.py`）。本文件只放样本。
> **登记**：`verify/skill_contracts.json` → `trigger_samples`；C6 机检分组数量。

## T 组 · 应触发（T≥8）

### T01
- Prompt：`把这些网盘资料整理成学习资料`
- 为什么该触发：网盘取料 + 资料整合是本技能主业
- 预期第一动作：`python3 scripts/learn.py intake pan`（先取料，取不到就报"无法判定"，不空跑后续）
- 不许：直接把网盘目录当本地文件扫

### T02
- Prompt：`这几篇公众号文章帮我做成资料`
- 为什么该触发：采集 → 分类 → 精炼 → 质检 → 入库全链
- 预期第一动作：`learn.py intake url <链接>` → `sort outline` 切知识点 → `gate run` 过闸
- 不许：直接复制正文拼成一个 md 就说完成任务（没过闸）

### T03
- Prompt：`这套资料能用吗`
- 为什么该触发：质检闸（覆盖率/答案自洽/难度分布/无出处必单列）
- 预期第一动作：`learn.py gate run`，输出四项逐条结论 + 不合格项清单
- 不许：只回一句"看着还行"

### T04
- Prompt：`这资料里有些结论没出处`
- 为什么该触发：grounding 检查 + 无出处必单列
- 预期第一动作：`learn.py gate grounding` → 列出无出处结论，**单列不删不改**
- 不许：替用户编一个来源（编造出处是红线）

### T05
- Prompt：`知识点太糊了，帮我切一下`
- 为什么该触发：分类整理（知识点切分/层级/去重/难度）
- 预期第一动作：`learn.py sort outline`
- 不许：按段落机械切（要按知识点）

### T06
- Prompt：`复习资料全不全，有没有漏考点`
- 为什么该触发：覆盖率检查
- 预期第一动作：`learn.py gate coverage`（给出覆盖了哪些、漏了哪些）
- 不许：凭感觉说"挺全的"

### T07
- Prompt：`这套资料入库吧，以后能查`
- 为什么该触发：入库与复用（不重复造）
- 预期第一动作：`learn.py store put`（主文档选 index.md > README.md > 唯一 md；多 md 无主则整包兜底）；收尾自动 `archive_out` 进「📚 学习资料」
- 不许：往云端丢一堆同名「index」文档（标题要用记录名）

### T08
- Prompt：`学习资料库里现在都有啥`
- 为什么该触发：树索引查看
- 预期第一动作：`learn.py store tree`
- 不许：靠 census 去猜哪些是学习资料

### T09
- Prompt：`这份资料跟以前那份是不是重了`
- 为什么该触发：去重是分类整理的一环
- 预期第一动作：`learn.py sort dedupe`（判重结论要给出依据：标题/知识点/内容片段的相似度）
- 不许：只比文件名

### T10
- Prompt：`这个网盘分享链接里的东西取下来`
- 为什么该触发：网盘取料是 intake pan 的明确能力
- 预期第一动作：`learn.py intake pan <链接>`；要凭据时向用户索取，**不落盘不回显**
- 不许：把 cookie/token 写进文件

## B 组 · 边界（B≥3）

### B01
- Prompt：`这块为什么老错，孩子记不住`
- 边界在哪：**学情诊断**属本技能（forge diagnose / schedule），但"出针对性的题"不属
- 正确处置：先 `learn.py forge diagnose` 定位薄弱点，再交给出卷技能做题
- 判失败的信号：诊断完顺手自己出题

### B02
- Prompt：`这份资料没出处，你帮我补上`
- 边界在哪：补出处 = 要么真找到源，要么标"无出处"
- 正确处置：能找到源就补并可追溯；找不到就**单列"无出处"**，不猜不编
- 判失败的信号：编一个看起来合理的来源

### B03
- Prompt：`帮我把这份资料改简单点`
- 边界在哪：内容改写 vs 资料整合（本技能只做"多源整合→可用资料"和质检编排）
- 正确处置：整合与质检在本技能；成篇改写明确说清归属，不在质检闸里偷偷改内容
- 判失败的信号：一边过闸一边改原文

### B04
- Prompt：`网盘链接给你，但要验证码`
- 边界在哪：取料需要用户配合（验证码/授权）
- 正确处置：`intake pan` 报缺什么就向用户要什么，状态记「受阻·待用户」，不假装取到了
- 判失败的信号：跳过取料直接"整理"空目录
