> **第一动作（自省锚点）**：命中触发词后**先读本技能全文**再动手；不许看见触发词/脚本就直接执行——

## 何时使用
- 触发词（唯一真源）：灰度 / 特性开关 / 切流 / 渐进发布 / 新旧并存 / 能回退吗 / 先小范围试试 / 别全开
- 接入新能力 / 新规则 / 新连接器，或用户要求小范围验证、可回退迭代时。

## 工作流
1. 为新能力建特性开关，默认 `off`，状态写入 git（如 `.codebuddy/config/feature-flags.json`）。
2. 新旧并存：保留旧路径与新路径，由开关路由。
3. 渐进切流：`1% → 10% → 50% → 100%`，或白名单先行。
4. 观测：异常即把开关拨回 `off`（瞬时回滚，无需回滚代码）。
5. 稳定后删除旧路径，完成绞杀。

## 职责与边界
- 只管切流与回滚机制，不实现新能力本身。
- 开关配置进 git、运行时读取，不硬编码；回滚 = 改开关，不留脏历史。
- 判定落在**配置**而非钩子（开关进 git、跨端一致、可秒级回滚；旧理由「手机不跑钩子」已作废，见 520pro `docs/钩子来源判定.md`）。
