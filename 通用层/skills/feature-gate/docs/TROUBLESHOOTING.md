# feature-gate · 故障排查（按症状查）

> **怎么用**：特性开关的坑是"**开关没开/开错地方/回滚不了**"。
> 机检：`verify/tests/test_troubleshoot.py` 要求 ≥5 条真实条目。

## 1. 开关打开了，但新能力没出现

- **先查**：开关文件在哪一版被读（仓内配置 / 环境变量 / 运行时目录）；默认值是 off 还是 on。
- **怎么办**：确认读的是**当前部署**的那份；改完要重启/新会话（很多开关只在启动时读一次）。
- **别做**：不要同时改两处（配置 + 环境变量）——冲突时你分不清哪个生效。

## 2. 换机/重装后开关状态丢了

- **先查**：开关状态有没有进 git（状态应进版本库，否则换机回到默认）。
- **怎么办**：把状态文件纳入仓库；重装后跑一次 `gate status` 对账。
- **别做**：不要把状态只放在 `~/.codebuddy/` 运行时目录——那不在分发范围。

## 3. 新旧两条路径都在跑，结果重复/打架

- **先查**：切流比例（0/10/50/100）与路由判据是不是同一个开关。
- **怎么办**：改回单一入口：开关只决定"走新还是走旧"，不要在两条路径里各写一半逻辑。
- **别做**：不要用"if 开关 then 新 else 旧"包住整段业务再各自演化——两条路径会分叉成两个产品。

## 4. 出事要回滚，找不到上一版行为

- **先查**：开关是否支持"瞬时回滚"（off 即回旧路径）；旧路径还在不在。
- **怎么办**：回滚只翻开关，不回滚代码；翻完观察一轮再决定是否保留新路径。
- **别做**：不要删掉旧路径——删了就只剩"改代码回滚"，窗口从秒变小时。

## 5. 开关在测试环境是 on，生产是 off，行为对不上

- **先查**：两个环境的开关来源是否同一份；有没有环境变量覆盖。
- **怎么办**：把"环境 → 开关值"写成一张表放进文档；每次发布前对一遍。
- **别做**：不要在代码里写死"生产默认 on"——那开关就成了摆设。
