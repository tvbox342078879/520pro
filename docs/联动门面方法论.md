# 生态联动门面 · 方法论

> 2026-11-12 实测沉淀。本文档来自对 `tvbox-core/scripts/core.py` 里两条门面
> （`file_to_janitor` / `register_monitor`）的正反向测试，不是设计推演。
>
> **一句话**：技能之间不该硬耦合，也不该假装耦合。门面要做的是「软接线 + 诚实报态」。

---

## 1. 为什么需要门面

技能生态里有两类调用：

| 类型 | 例子 | 特征 |
|---|---|---|
| **硬依赖** | `probe-hub` 需要 `tvbox-core/scripts/core.py` | 缺了**必须崩**，因为主流程走不下去 |
| **旁路联动** | 采完料顺手把残留投递给清道夫 | 缺了**不该崩**，因为主流程已经完成了 |

硬依赖用 `import` 就对了，崩得越早越好。

旁路联动不行——如果探源司因为「清道夫没装」而退出，那是拿支线故障杀主线。
但反过来，如果它**静默跳过**，用户永远不知道那条支线从没通。

门面就是解决这个矛盾的：**失败要能被看见，但不能阻断**。

---

## 2. 四条铁律

### 铁律一：软导入，不在模块顶层 import 下游

```python
# ✗ 错：模块顶层 import，下游没装 → 整个技能起不来
from janitor import auto_file

# ✓ 对：调用时才插路径、才导入
def file_to_janitor(node_id, reason='', quiet=True):
    JAN = os.path.expanduser('~/.codebuddy/skills/tvbox-janitor/scripts')
    if JAN not in sys.path:
        sys.path.insert(0, JAN)
    import janitor
    return bool(janitor.auto_file(node_id, reason, quiet=quiet))
```

**判据**：把这个函数所在的文件单独 import，不该有任何下游模块被加载。

### 铁律二：失败返回 `False`，不抛异常

```python
try:
    ...
    return bool(janitor.auto_file(...))
except Exception as e:
    if not quiet:
        print(f'  ⚠️ 清道夫联动失败（{type(e).__name__}）：节点 {node_id} 未投递，请人工删')
    return False
```

**为什么吞异常是对的**：这是旁路。主线（采集/入库/出配置）已经跑完了，
下游投递失败只意味着「这条残留要人工删」，不意味着「本次任务失败」。

**但吞异常必须留痕**：`quiet=False` 时要把异常类型和后果打出来。
只 `pass` 的 `except` 是静默失败，比崩溃更坏。

### 铁律三：`quiet` 默认 `True`，但参数错不静默

批量调用（一次投 40 条）时逐条打警告会淹掉真正的输出，所以默认静默。
但**参数错误是调用方的 bug，不是运行时抖动**，必须无视 `quiet` 直接报：

```python
if not _NODE_ID_RE.match(nid):
    print(f'  ❌ 清道夫投递被拒：入参不是云端 node_id → {nid[:70]!r}')
    return False
```

这条来自真实事故（S156）：`blk.py` 长期调用时传的是**描述文字**而不是 `node_id`，
于是「查不到 → 移动失败 → 但仍登记进清单」，清单显示 40 项、收件箱实际 18 个。
**看起来在跑、有调用、有记录，核心动作一次都没成功。**

### 铁律四：入参先校验形状，再动手

云端节点 id 有固定形状（`^[A-Za-z0-9_-]{16,32}$`）。校验它，比校验「下游是否活着」更重要——
因为**下游活着的时候，错参数也不会报错，只会静默做错事**。

---

## 3. 三态：门面必须能报「无法判定」

门面的返回值不能只有 True/False。要有第三种：

| 返回 | 含义 | 处置 |
|---|---|---|
| `True` | 真投递成功 | 正常 |
| `False` | 下游在，但调用失败 / 参数错 | 告警，人工兜底 |
| `None` | **下游没装** | 无法判定，不算失败 |

`None` 这一档是最容易被省掉的，也是最有价值的。

---

## 4. 最危险的坑：`callable()` 不是「可达」

**实测证据（2026-11-12）**：

```python
# 修复前的探针
def _eco_linked_probe():
    return (callable(file_to_janitor), callable(register_monitor))
```

`file_to_janitor` 定义在 `core.py` 里。只要 `import core` 成功，它就 `callable`。
于是当下游一个都没装时：

```
_eco_linked_probe() = (True, True)
下游是否存在: tvbox-janitor=False  tvbox-inspect=False
```

自检报「生态联动门面可达 ✅」。**这是假阳性，比报红更危险**——报红会有人去修，
假绿会让人以为这条链一直是通的。

**正确的判据**：探下游的**目录存在 + 符号可导入**，而不是探本地函数能不能被调用。

```python
def _probe(dirp, modname, attr):
    d = os.path.expanduser(dirp)
    if not os.path.isdir(d):
        return None                      # 未装 → 无法判定
    try:
        sys.path.insert(0, d)
        m = importlib.import_module(modname)
        return True if callable(getattr(m, attr, None)) else False
    except Exception:
        return False
```

修复后同一环境：

```
· 生态联动门面可达：无法判定（下游未装：清道夫 tvbox-janitor、监察司 tvbox-inspect）
```

## 5. 怎么验证门面是真的

**造一个假下游**，比读代码可靠。假下游只做两件事：写一行日志、返回 True。

```bash
mkdir -p ~/.codebuddy/skills/tvbox-janitor/scripts
cat > ~/.codebuddy/skills/tvbox-janitor/scripts/janitor.py <<'PY'
def auto_file(node_id, reason='', quiet=True):
    with open('/tmp/janitor_called.log', 'a') as f:
        f.write(f'{node_id}|{reason}\n')
    return True
PY
```

然后调用门面，看三件事：

| 看什么 | 说明 |
|---|---|
| 返回值是否 `True` | 门面的返回值通不通 |
| 日志里有没有那条记录 | **下游是否真的被调到**（只看返回值会被自己的 return 骗） |
| 删掉假下游后是否返回 `False` 且不抛 | 失败路径是否成立 |

实测结果（2026-11-12）：

```
正A：返回 True，下游日志 tBlgSL4SPEFMrsyTBTg03c|测试投递
正B：返回 True，下游日志 废弃节点堆积|naming_compliance
反A：传描述文字 → ❌ 投递被拒 → False
反B：删下游 → ⚠️ ModuleNotFoundError → False（未抛异常）
```

**四条全成立，才叫机制可用。**

## 7. 复用清单

新写一个门面时，逐条对：

- [ ] 下游路径用 `os.path.expanduser`，不写死 `/root`
- [ ] 不在模块顶层 import 下游
- [ ] `except` 里保留异常类型，`quiet=False` 时打印后果
- [ ] 返回值三态：`True` / `False` / `None`（未装）
- [ ] 入参先做形状校验，参数错不静默
- [ ] 自检探的是「下游在不在」，不是「本地函数 callable 吗」
- [ ] 有假下游的验证记录（返回值和日志都要看）

## 附：这条方法论从哪来

不是设计出来的，是三条事故倒逼出来的：

1. **S156 假账**：传描述文字当 `node_id`，清单 40 项、实际 18 项——名义联动。
2. **S104 静默跳过**：`except: pass` 让「没投递」这件事三个月没人发现。
3. **2026-11-12 假阳性**：`callable()` 探针在下游全缺时报绿——名义可达。

三条的共同点：**系统在运行、有输出、看起来正常，但核心动作一次都没发生。**
