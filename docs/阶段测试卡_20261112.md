## 四、三个已知陷阱

1. **HOME 不匹配 → 假 `ModuleNotFoundError`**：所有脚本用 `~/.codebuddy` 定位共享库。换 HOME 测必须整条链路一起换。
2. **443 出站受限 → A3 记「无法判定」**：机房 IP 下 `monitor check --repo` 单目标常超时无输出，这是网络不是能力；`monitor status` 走本地登记，不受影响。
3. **`--dry-run` 不落盘**：只打印 `[dry-run] ...`，跑完什么都没装。别把它当装过。
