## 二、升机检两项的确定性信号

**S-09 搜索顺序**：判据对象是"查/看类指令的查证回复里，是否出现会话范围取证痕迹"。确定性形态 = 回复正文出现会话取证标记（`会话.jsonl:<行号>` / `transcript` / `payloads/` 之一）。不判"是否真扫了"（病15：识别范围≠对象范围），只判标记在不在——与 B-06 同型（判引证在不在，不判引证真伪）。

**派单·子代理语言**：判据对象是"本轮派子代理的 prompt 首句是否含'全程简体中文'"。确定性形态 = 派单文本命中固定短语。当前靠我在 prompt 里手写，本阶段后固化为派单模板首句。

## 三、统一入口（不造新闸）

复用 `hooks/stop_guard.py` 现有 `judge_*` 拽回链，新增 `judge_s_discipline()`：

- 接两项可机检信号（S-09 会话取证标记、子代理语言标记）
- 保守优先（沿用文件头协议）：只在"查类指令 + 回复缺会话标记"时命中，宁放过不误伤
- 判据坏（trace 加载失败）fail-open
- 拽回文案单行（踩过多行字段被注入截断的坑）
- 判定顺序追加在 B-06 之后：B-13 → B-03/07 → B-18 → B-06 → **S-discipline**
